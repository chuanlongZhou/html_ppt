# ADR-008 位图操作：图片坐标中的放大与标注

- 状态：已采纳（M0.5，用户需求"操作位图的效果"）
- 背景：演示中大量使用截图和照片，常见操作是放大局部、加箭头、画圈、文字强调、聚光、前后对比。如果让 AI 手算舞台坐标，图片一放大，所有标注都要重新计算，而且容易出错。
- 决定：
  - 引擎在编译期读取图片的原始尺寸（`imagesize.ts`），由 `imageGeom()` 计算 fit（cover / contain）与 `zoom: { at, scale }` 之后的图片矩形；`<img>` 以绝对定位渲染，zoom 在 State 之间可以插值。
  - 标注对象写 `on: <图片 key>`，位置写成图片坐标 `box: [u, v, w, h]`（line 用 `from` / `to`），取值 0–1。引擎按该 State 的图片几何换算成舞台坐标，所以图片 zoom 变化时标注会跟着走。
  - 标注首次出现时，在上一个 State 中按当时的几何放一个透明幽灵，让它随镜头移动并淡入，而不是先出现在终点。
  - 新增 `spotlight` 形状（透明洞 + 外扩阴影）与图片 `filter` 属性。
  - 嵌套 morph 规则：图片内部元素相对父容器插值（runtime.js 的 NESTED 选项）。
- 后果：AI 只需描述"在图片的哪个位置"；QA 会对放大后落在可见区域外的标注给出 ANNOTATION_OUTSIDE 警告。为 M1 的 PPTX 复刻（图片裁剪、局部放大动画）提供了基础。
